# Panchakshara Entertainment — Indian OTT design v0.4

## Update
- Indian entertainment hub visual style with navy and electric blue
- Original Panchakshara logo in the header
- Rich but lightweight animations, hover effects and cinematic hero styling
- Preserves prototype browsing, genre/language filters, Creator Studio metadata, and demo video player

## GitHub update
Upload/replace `index.html` at the root of the existing repository, and upload the `assets` folder so `assets/panchakshara-logo.png` exists. Commit changes, wait for GitHub Pages to deploy, then hard-refresh the website (Ctrl+F5).

## Prototype limitations
This remains a front-end demo. Video uploads are not stored on a public server, content is not synchronized across devices, and login, creator permissions, database, real payment verification and subscription enforcement still need backend integration. Use only video content you own or have permission to distribute.
